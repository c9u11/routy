# 게임 자체등급분류 → 앱스인토스 콘솔 입력 런북 (Routy / 길찾기 퍼즐)

목적: 게임물관리위원회(GRAC) 자체등급분류 등록 결과를 **앱인토스 콘솔 > 앱 등록 > 게임 등급분류 탭**에 입력해, `docs/toss-deploy.md`의 "검토 요청" 전 단계를 충족한다.
참고: https://toss.im/apps-in-toss/blog/self-rated_game_distribution

> ⚠️ 콘솔 입력값은 **자체등급분류를 받을 당시의 App Store(애플) 등급 정보와 정확히 일치**해야 한다. 불일치/미작성 시 행정조치 대상이 될 수 있다.

## GRAC 조회 결과

| 항목 | 값 |
|---|---|
| 등급분류번호 | `AAPL-SM-260603-0403` |
| 게임물명 | 길찾기 퍼즐 |
| 등급분류일자 | 2026-05-30 |
| 장르 | 퍼즐 |
| 등급 | 전체이용가 |

접두사 `AAPL` = 애플 App Store를 통한 자체등급분류.

## 1단계 — 기본정보
- 사업자등록증(있으면) 또는 개인 정보 입력. 개인 개발자는 개인 명의로 진행.

## 2단계 — 게임물 정보

| 콘솔 필드 | 입력값 | 출처 |
|---|---|---|
| 등록자명 | **SEOKYOUNG HWANG** (App Store 개발자명, id 6774656806) | App Store Connect |

## 3단계 — 게임 플레이 화면 (4장)
- **자체등급분류 당시 화면 2장** = App Store에 올린 스크린샷 중 2장
  → `assets/appstore/screenshots/{01-home,02-speed,03-infinity}.png` 중 2장
- **앱스인토스 내 화면 2장** = 토스 샌드박스 미리보기에서 신규 캡처 (홈 + 플레이 화면)

## 4단계 — 추가 이미지
- 선정성·폭력성 장면 → **없음** (전체이용가, 해당 없음이므로 제출 불필요).

## 직접 채워야 하는 항목 (체크리스트)
- [x] 등록자명 = SEOKYOUNG HWANG
- [ ] 대표자 인감/사인 이미지 파일
- [ ] 앱스인토스 내 게임 화면 2장 (토스 샌드박스 신규 캡처)

## 검증
- 콘솔 입력 후 GRAC 자체분류게임물 검색 결과 5개 항목과 콘솔 표기를 1:1 육안 대조.
- 미작성 항목 없는지 확인.
