# Routy (길찾기 퍼즐) 개인정보 처리방침

**최종 수정**: 2026-05-29

## 1. 수집하는 정보

Routy는 **사용자 식별 정보를 수집하지 않습니다**. 어떤 종류의 회원가입·로그인·계정도 요구하지 않으며, 개발자 또는 제3자 서버로 전송되는 사용자 데이터가 없습니다.

## 2. 단말기 내 저장 데이터

다음 데이터만 사용자의 단말기 내(웹뷰의 `localStorage`)에 저장되며, 외부로 전송되지 않습니다:

| 항목 | 용도 |
|---|---|
| `best_SPEED` | Speed 모드 최고 점수 |
| `best_INFINITY` | Infinity 모드 최고 점수 |
| `nc_tutorial_done` | 튜토리얼 시청 여부 |
| `routy_settings_v1` | 진동·흔들림·사운드 토글 상태 |

해당 데이터는 토스 앱 또는 브라우저의 데이터 삭제 기능으로 언제든 제거할 수 있습니다.

## 3. 제3자 공유

Routy는 **어떠한 제3자와도 사용자 데이터를 공유하지 않습니다.** 광고 네트워크, 분석 도구, 외부 API를 사용하지 않습니다.

## 4. 권한

본 앱은 다음 시스템 기능만 사용합니다:
- **햅틱(진동)**: 게임 피드백 — 토스 SDK `generateHapticFeedback`
- **로컬 스토리지**: 점수 / 설정 저장 (위 2번 항목)

별도의 카메라·위치·연락처·앨범 권한을 요구하지 않습니다.
