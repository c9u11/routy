Routy (길찾기 퍼즐) 개인정보 처리방침

최종 수정: 2026-05-29

1. 수집하는 정보

Routy는 사용자 식별 정보를 수집하지 않습니다. 어떤 종류의 회원가입·로그인·계정도 요구하지 않으며, 개발자 또는 제3자 서버로 전송되는 사용자 데이터가 없습니다.

2. 단말기 내 저장 데이터

다음 데이터만 사용자의 단말기 내에 저장되며, 외부로 전송되지 않습니다.

항목용도
best_SPEEDSpeed 모드 최고 점수
best_INFINITYInfinity 모드 최고 점수
nc_tutorial_done튜토리얼 시청 여부
routy_settings_v1진동·흔들림·사운드 토글 상태
  • 웹 환경: 브라우저의 localStorage
  • 토스 인앱: localStorage와 함께 토스 미니앱 Storage(@apps-in-toss/web-framework의 Storage)에 같은 키로 미러 저장. 토스 앱 캐시 정리나 재설치 시에도 진행도가 보존되도록 함.

해당 데이터는 토스 앱 또는 브라우저의 데이터 삭제 기능으로 언제든 제거할 수 있습니다. 토스 미니앱 환경에서는 미니앱 내비게이션 바 > 설정 > "미니앱 용량 삭제"로도 제거 가능합니다.

3. 토스 익명 식별 키

토스 인앱에서 실행될 때, 토스 SDK의 getAnonymousKey()로 발급되는 익명 해시 값을 수신할 수 있습니다.

  • 사용자의 이름·전화번호·이메일 같은 개인식별정보(PII)가 아닙니다.
  • 토스 사용자 ID도 아닙니다.
  • 동일 미니앱 내에서 같은 사용자가 일관된 hash를 얻는 단순 식별자입니다.
  • 현재는 캐시 외 용도로 사용되지 않으며, 향후 리더보드/광고 보상 어뷰징 방지 등에서 활용될 수 있습니다.
  • 외부 서버로 전송되지 않습니다.

4. 제3자 공유

Routy는 어떠한 제3자와도 사용자 데이터를 공유하지 않습니다. 광고 네트워크, 분석 도구, 외부 API를 사용하지 않습니다.

5. 권한

본 앱은 다음 시스템 기능만 사용합니다.

  • 햅틱(진동): 게임 피드백 — 토스 SDK generateHapticFeedback
  • 로컬/미니앱 Storage: 점수 / 설정 저장 (위 2번 항목)
  • 익명 식별 키: 위 3번 항목

별도의 카메라·위치·연락처·앨범·결제 권한을 요구하지 않습니다.
